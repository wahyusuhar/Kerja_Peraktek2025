### ✨ Tentang Aplikasi
Aplikasi **Point of Sales (POS)** ini dirancang untuk membantu proses transaksi dan manajemen toko dengan mudah dan efisien.  
Dibangun menggunakan **Laravel 8** dengan minimal **PHP 7.4**.

Sangat cocok untuk:
- Toko Retail
- Toko Sembako
- Minimarket
- Swalayan
- Koperasi
- UMKM

---

### 🚀 Fitur Utama

| Fitur | Deskripsi |
|------|-----------|
| **Manajemen Produk** | Tambah, edit, multiple delete, & cetak barcode |
| **Manajemen Member** | Tambah anggota & cetak kartu member custom |
| **Manajemen Supplier** | Kelola pemasok barang |
| **Transaksi** | Pembelian, Penjualan, dan Pengeluaran |
| **Laporan Pendapatan** | Laba Rugi: Harian, Bulanan, dan Custom |
| **Jenis Nota** | Nota Besar & Thermal Printer / struk kecil |
| **Pengaturan Toko** | Identitas toko, desain kartu, diskon member |
| **Level User** | Role: Admin & Kasir |
| **Dashboard ChartJS** | Grafik transaksi realtime |
